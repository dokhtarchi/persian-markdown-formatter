# پروژه مدیریت جلسات

این یک مستند برای پروژه مدیریت جلسات است که با python نوشته شده و از `Meeting Offset` و `Cooldown` استفاده می کند.

## نصب

برای نصب اول باید python را نصب کنید بعد git را نصب کنید و در نهایت با دستور pip install -r requirements.txt وابستگی ها را نصب کنید.

## ویژگی ها

ثبت جلسه
یادآور خودکار
گزارش هفتگی

## تنظیمات

تنظیم روزها ۵ هفته ها ۲ و ماه ۱ است. همچنین `Session Offset` برابر 30 و `Cooldown` برابر 5 است.

> این ابزار معامله انجام نمی دهد.
